# Orc variant notes

Four distinct original orcs on the original front-only extra sheet. Wiry reuses the accepted canonical orc front. Other identities retain the original mottled grey-green to brown skin, scars, fangs, matted hair, rag armour and rusted plates. All hold cleaver in own right hand; left empty. Common code scale uses each authored overall height within the original humanoid scale family. No mirrored source.
